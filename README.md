# ai-project

たかとAIが、実際の経験・試行錯誤・判断・気づきを蓄積し、将来の自動化・記事化へつなげるための共有情報庫です。

## AI・バドがこのリポジトリを初めて読む場合

**最初に [`BUD.md`](./BUD.md) を読んでください。**

読解順と、現在資料と過去資料をどう区別するかは [`docs/AI_READ_MAP.md`](./docs/AI_READ_MAP.md) に定義しています。

### 推奨読解順

1. [`BUD.md`](./BUD.md) — 最上位コンテキスト
2. [`docs/AI_READ_MAP.md`](./docs/AI_READ_MAP.md) — 読解順・情報の優先順位・分類
3. [`docs/00_CURRENT_STATE.md`](./docs/00_CURRENT_STATE.md) — 2026-09-07現在の状態
4. [`rules/README.md`](./rules/README.md) — 現在有効な運用ルール
5. [`projects/README.md`](./projects/README.md) — 取り組みの一覧と位置づけ
6. [`経験ログ/`](./経験ログ/) — 実際に発生した経験
7. [`直チャット/`](./直チャット/) — 一次記録として保存された会話・作業ログ
8. 旧資料 — `docs/` や `指針等/` の過去資料は、現在資料との整合を確認しながら履歴として参照

## 重要な読み方

- **現在の方針・現在状態は、過去の記録より優先する。**
- 過去にJUNやClaudeを利用した事実は、現在の固定的な役割分担を意味しない。
- たか＋バドだけで完結できる作業は、それだけで完結してよい。
- 詳細な過去資料に現在とは異なる役割記述があっても、まず現在資料を確認する。
- 直チャットは原文を基本記録とし、経験DBへの整理は別途行う。
- 画像は主記録ではなく、必要な場合の補助記録として扱う。

## 現在の主要テーマ

- VAIO Pを今後の自動化の実運用基盤として整備する
- DIGA関連の自動化を進める。特に「お気に入り・機種別制御・警告メール」は今後VAIO Pで自動化を進める重要な取り組み
- 経験DBを継続的に育てる
- GAS等の既存資産とVAIO Pを適切に接続する
- 将来的に経験ログから記事素材を発見し、Bloggerへの記事作成・投稿につなげる

## 現在の中心

**たかが中心で、バドがたかと一緒に進める。**

バドは必要に応じて、過去経験の検索・整理、設計、分析、提案、文章化、実装、検証、経験資産化などを担当できます。JUN・Claude・その他のAIやツールは必要に応じて使う補助手段であり、固定役割ではありません。

## 既存の主な情報領域

- `docs/` — 設計・現状台帳・マスタープラン等
- `指針等/` — 運用上の基準・ID管理等
- `直チャット/` — 実際の会話・作業の原文記録
- `経験ログ/` — EXP / RECとして整理した経験
- `projects/` — 取り組みの現在位置を整理する入口
- `rules/` — 現在有効な運用ルールを整理する入口
