# ai-project

たかとAIが、実際の経験・試行錯誤・判断・気づきを蓄積し、将来の自動化・記事化へつなげるための共有情報庫です。

## AI・バドがこのリポジトリを初めて読む場合

**最初に [`BUD.md`](./BUD.md) を読んでください。**

このREADMEは入口です。現在の基本認識・役割・運用ルールは、過去の作業記録から推測せず、BUD.mdとそこから案内される現在資料を優先してください。

### 推奨読解順

1. [`BUD.md`](./BUD.md) — このリポジトリを理解するための最上位コンテキスト
2. [`docs/00_CURRENT_STATE.md`](./docs/00_CURRENT_STATE.md) — 2026-09-07現在の状態
3. [`rules/README.md`](./rules/README.md) — 現在有効な運用ルールの入口
4. [`projects/README.md`](./projects/README.md) — 取り組みの一覧と位置づけ
5. [`経験ログ/`](./経験ログ/) — 実際に発生した経験
6. [`直チャット/`](./直チャット/) — 一次記録として保存された会話・作業ログ
7. `history/` — 過去の経緯（必要になった場合に参照）

## 重要な読み方

- **現在の方針・現在状態は、過去の記録より優先する。**
- 過去にJUNやClaudeを利用した事実は、現在の固定的な役割分担を意味しない。
- たか＋バドだけで完結できる作業は、それだけで完結してよい。
- 詳細な過去資料に現在とは異なる役割記述があっても、まずBUD.md / CURRENT_STATE / rulesを確認する。
- 直チャットは原文を基本記録とし、経験DBへの整理は別途行う。
- 画像は主記録ではなく、必要な場合の補助記録として扱う。

## 現在の主要テーマ

- VAIO Pを今後の自動化の実運用基盤として整備する
- DIGA関連の自動化を進める。特に「お気に入り・機種別制御・警告メール」は今後VAIO Pで自動化を進める重要な取り組み
- 経験DBを継続的に育てる
- GAS等の既存資産とVAIO Pを適切に接続する
- 将来的に経験ログから記事素材を発見し、Bloggerへの記事作成・投稿につなげる

## 既存の主な情報領域

- `docs/` — 設計・現状台帳・マスタープラン等
- `指針等/` — 運用上の基準・ID管理等
- `直チャット/` — 実際の会話・作業の原文記録
- `経験ログ/` — EXP / RECとして整理した経験
- `projects/` — 取り組みの現在位置を整理する入口
- `rules/` — 現在有効な運用ルールを整理する入口
