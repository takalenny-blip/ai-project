# ai-project

たかとAIが、実際の経験・試行錯誤・判断・気づきを蓄積し、将来の自動化・記事化へつなげるための共有情報庫です。

## 最初に読む資料

- [`rules/運用ルール.md`](./rules/運用ルール.md)：現在状態・共通運用ルールの唯一の正本。新しいチャットの開始時・作業再開時は最初に読む。
- Dropbox `/ChatGPT/Dropbox作業管理統合ボード.xlsx`：日常作業キュー・優先度・状態・次のアクションの唯一の正本。
- 操作に応じて、`rules/運用ルール.md` の読み込み表が指定する操作別ルールを読む。
- 必要な場合だけ、対象プロジェクト資料・経験ログ・GitHubの直チャット原本を読む。

## 起動時・再開時の必須確認

1. `rules/運用ルール.md` を読み、現在の方針・実行環境・禁止事項・停止条件を確認する。
2. 日常作業の候補・状態・優先順位・次の行動はDropbox固定ボードから取得する。ボードが読めない場合は停止し、過去ログや古い資料から補完しない。
3. 画像は、たか本人の明示的な許可がない限り、表示・検索・生成しない。サムネイル・プレビュー・画像表示コンポーネントも使用しない。
4. 回答前に、依頼範囲・根拠・確定事項と未確認事項を点検する。許可や必要資料を確認できない場合は、影響する作業を止める。

## 情報の役割

- `rules/運用ルール.md`：現在状態・共通運用ルール・採用済み方針・実行環境・既知の制約。
- Dropbox固定ボード：日常作業キュー。
- `rules/` 内の操作別ルール：個別操作の詳細手順。
- `直チャット/`：明示的に保存された会話の一次記録。既存原本は変更・削除・改名・上書き・置換しない。
- `経験ログ/`、`projects/`、`docs/`：各成果物・設計・履歴。現在の運用ルールを上書きしない。

## 現在の主要方針

- 主な公開工程は「経験ログ → Blogger下書き・表示確認 → GitHub Pages本番公開」。
- DIGA / DiMORA自動化は2026-09-21に本線作業を断念。過去の成果・経験は履歴として保持する。
- WordPressは本番公開先として扱わない。
- 現行の実行環境は `work_pc`。`vaio_p` は退役済み。

## 構造変更時の確認

構造変更後は、README、運用ルール、保存・再開処理、CI、テストが同じ運用実態を示しているか確認する。未確認の項目を完了扱いにしない。

## 秘密情報

公開GitHubにはパスワード、APIキー、アクセストークン、Cookie、その他の認証情報や公開すべきでない個人情報を保存しません。
