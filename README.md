# ai-project

たかとAIが、実際の経験・試行錯誤・判断・気づきを蓄積し、将来の自動化・記事化へつなげるための共有情報庫です。

## AI・バドがこのリポジトリを初めて読む場合

**最初に [`BUD.md`](./BUD.md) を読んでください。**

BUDに現在の目的・現在状態・現在の次の一手を集約しています。作業手順・運用ルールは [`rules/運用ルール.md`](./rules/運用ルール.md) に一本化しています。

### 推奨読解順

1. [`BUD.md`](./BUD.md) — 現在の目的・状態・次の一手
2. [`rules/運用ルール.md`](./rules/運用ルール.md) — 作業手順・運用ルール
3. [`docs/引き継ぎ/現在の引き継ぎ.md`](./docs/引き継ぎ/現在の引き継ぎ.md) — 直前セッションの再開情報
4. [`projects/`](./projects/) — 関係するプロジェクト資料
5. [`経験ログ/`](./経験ログ/) — 必要なEXP / REC
6. [`直チャット/`](./直チャット/) — 必要な一次記録
7. 旧資料 — 経緯・出所・歴史を調べる必要がある場合のみ参照

`docs/AI_READ_MAP.md` は読解順の補助マップ、`rules/README.md` は運用ルールの入口です。どちらもBUDの現在状態を上書きしません。

## 重要な読み方

- **現在の方針・現在状態は、過去の記録より優先する。**
- 過去ログの「次にやること」は現在の命令ではない。
- たか＋バドだけで完結できる作業は、それだけで完結してよい。
- 過去にJUNやClaudeを利用した事実は、現在の固定的な役割分担を意味しない。
- 直チャットは原文を一次記録とし、経験DBへの整理は別途行う。
- 画像は主記録ではなく、必要な場合の補助記録として扱う。

## 現在の主要テーマ

- VAIO Pを今後の自動化の実運用基盤として整備する
- DIGA関連の自動化を進める。特に「お気に入り・機種別制御・警告メール」は今後VAIO Pで自動化を進める重要な取り組み
- 経験DBを継続的に育てる
- GAS等の既存資産とVAIO Pを適切に接続する
- 将来的に経験ログから記事素材を発見し、Bloggerへの記事作成・投稿につなげる

## 現在の中心

**たかが中心で、バドがたかと一緒に進める。**

## 既存の主な情報領域

- `docs/` — 設計・台帳・歴史資料等
- `指針等/` — 基準・ID管理等
- `直チャット/` — 実際の会話・作業の原文記録
- `経験ログ/` — EXP / RECとして整理した経験
- `projects/` — 取り組みの資料
- `rules/` — 現在有効な運用ルール
