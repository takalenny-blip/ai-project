### バグ1：連番計算

`next_serial()` が全期間の3桁連番最大値を使っている。

過去に `2026-09-13_直チャット即時保存_999.md` が存在するため、最大値999から1000を返し、
`serial must be exactly three digits`
で失敗する。

**最小修正案：**
当日の日付に属する3桁連番だけを対象にし、当日分の最大値+1とする。

### バグ2：integrity checkの実行順序

新しい直チャットファイルを書いた後、まだ `git add` していない状態で `check_repo_integrity.py` を実行している。

`check_repo_integrity.py` の `git_files()` は `git ls-files` を使うため、新規未trackedファイルを見落とし、
`FAIL: latest direct-chat path missing`
になる。

**最小修正案：**
順序を

`write → git add → integrity check → 一致確認 → commit`

に変更する。
