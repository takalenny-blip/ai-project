# 直チャット即時保存

- 保存対象種別: 会話記録
- 対象日時: 2026-09-25
- 記録方式: User発言＋直後のBud回答

## User

ブログ番号もファイル名につけてくれ。

## Bud

了解。**ブログ番号をファイル名に含める**形にしよう。

たとえば BLOG-0001 なら：

```
BLOG-0001_ver00001.html
BLOG-0001_ver00002.html
BLOG-0001_ver00003.html
```

運用としては、

- 「HTMLバックアップ」→ 現在のHTMLを次の番号でコピー
- 初回 → `BLOG-0001_ver00001.html`
- 次回 → `BLOG-0001_ver00002.html`
- 「Ver.00002に戻して」→ その版を現在HTMLへ復元
- 元ファイルのGit履歴も残す
- **バックアップ操作では記事本文そのものは変更しない**

で統一するのが分かりやすい。

この命名規則を前提に、次は**実装仕様として固める**段階。
