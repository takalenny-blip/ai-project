### 実装したもの

` scripts/search_direct_chat.py ` を追加した。

この検索経路は、次の順番で動く。

1. GitHub Contents APIで `直チャット/` のファイル一覧を取得する。
2. 一覧から一次記録ファイルを取得する。
3. 各本文をAI側ではなく、軽量なPythonの文字列検索で全文走査する。
4. ファイル名・行番号・前後の行を結果として出す。
5. 標準では大文字小文字を無視し、必要なら `--case-sensitive` で厳密検索できる。

つまり、GitHubのコード検索indexには依存しない。

例：

```bash
python3 scripts/search_direct_chat.py chromium
```

今回の既知の事実確認では、GitHub APIから `直チャット/` の一覧取得ができ、さらに `048` の本文を直接取得して `~/.config/chromium-flags/launch-light.sh` を確認できた。このAPI経路自体は成立している。

実装ファイルはGitHubへ保存し、読み戻し確認済み。コミットは `f3f9d1f1e2835f469a15f61d7e105dee0ee45f7d`。
