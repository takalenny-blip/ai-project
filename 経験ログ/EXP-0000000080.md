# EXP-0000000080

## タイトル
BLOG-0001公開後のGSC「Redirect error」調査と経過観察判断

## 内容
2026-09-26〜2026-09-27、BLOG-0001公開後のGoogle Search Console URL検査で「Redirect error」が記録されている件を調査した。

GSC一次情報では、正規URL
`https://taka-since2025.blogspot.com/2026/09/blog-post.html`
について、2026-09-26 06:32:41 UTCのクロールで、ページ取得がREDIRECT_ERRORとなっていた。robots.txtはALLOWED、クロールはモバイル。末尾スラッシュ版はGoogleに認識されておらず404として扱われた。

Blogger管理画面の「設定→エラーとリダイレクト→カスタムリダイレクト」は「アイテムなし」で、ユーザー設定のカスタムリダイレクトは確認されなかった。

クロウによる読み取り専用調査では、Bloggerのモバイル向け標準動作として`?m=1`を伴う302リダイレクトが関係している可能性が高く、ページのcanonicalはデスクトップ正規URLを指していることを確認した。ただし、今回のGSC Redirect errorがこの挙動だけで発生したことまで独立証明できたわけではない。

また、調査ツール経由ではGoogleの`google.com/sorry/`にHTTP 429が返る事象も確認されたが、これはGoogle側のレート制限・自動取得対策等の可能性があり、BLOG-0001自体の障害原因とは未確認である。

## 結果・判断
- 確認済み：Bloggerのカスタムリダイレクトは登録なし。
- 確認済み：GSCではBLOG-0001がRedirect errorとして記録されている。
- 確認済み：canonicalはBLOG-0001の非`?m=1`正規URL。
- 判断：Blogger標準の`?m=1`リダイレクト挙動は原因候補として記録するが、原因確定とはしない。
- 判断：現時点ではBlogger側の設定変更を行わない。
- 判断：数日〜1週間後にGSCで状態・インデックス状況を再確認する。
- 未確認：調査ツールで観測した`google.com/sorry/` HTTP 429の発生原因。

## 未完了・保留
- GSCのRedirect errorが解消するか、インデックス登録に進むかの経過確認。
- 改善しない場合は、新しいGSC一次情報を根拠に次の調査方法を決める。
- `google.com/sorry/` HTTP 429の原因は現時点では追わず保留する。
