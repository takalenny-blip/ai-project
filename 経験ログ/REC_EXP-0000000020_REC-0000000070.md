# REC-0000000070

## EXP-ID
EXP-0000000020

## 日時
2026-09-05

## タイトル
VAIO Type PのDebian環境でWi-Fi接続を復旧する

## 内容
Debianを導入したVAIO Type Pで、Wi-Fiが利用できない状態を確認した。USBテザリングなどを試しながらNetworkManagerを導入し、無線インターフェース `wlp2s0` がunmanagedになっていることを確認した。

`/etc/network/interfaces` の無線設定がNetworkManagerによる管理を妨げている可能性を確認し、該当する無線設定をコメントアウトしてNetworkManagerを再起動した。その後、Wi-FiのSSIDが表示され、無線LANへ接続できる状態まで復旧した。

## 結果
VAIO Type PのDebian環境でWi-Fi接続を復旧できた。

## 気づき
Wi-Fiが単純に「認識していない」のではなく、`wlp2s0` がNetworkManagerからunmanagedとして扱われていたことが原因切り分けの重要なポイントになった。Debianのネットワーク設定では、`/etc/network/interfaces` とNetworkManagerの管理関係を確認することが有効だと分かった。
