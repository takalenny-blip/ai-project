# EXP-0000000080 / REC-0000000010

## 所属EXP
EXP-0000000080

## タイトル
BLOG-0001公開後のGSC「Redirect error」調査結果

## 記録
BLOG-0001の公開後、Google Search Consoleで正規URLのURL検査を行ったところ、2026-09-26 06:32:41 UTCのクロールについて「Redirect error」が記録された。

確認したURL：
`https://taka-since2025.blogspot.com/2026/09/blog-post.html`

GSCで確認された主な状態：
- robots.txt：ALLOWED
- indexing state：INDEXING_STATE_UNSPECIFIED
- page fetch：REDIRECT_ERROR
- crawled as：MOBILE
- referring URLs：none

末尾スラッシュ版
`https://taka-since2025.blogspot.com/2026/09/blog-post.html/`
はGoogleに認識されておらず、別URLとして404相当の状態だった。

Blogger管理画面では、カスタムリダイレクトは「アイテムなし」だった。

クロウの読み取り専用調査では、Blogger標準のモバイル向け`?m=1`リダイレクトとcanonicalの組み合わせが今回のRedirect errorの原因候補と整理された。canonical自体は正規の非`?m=1` URLを指している。原因を完全に証明したものではないため、原因確定とは扱わない。

調査ツール経由で`google.com/sorry/` HTTP 429も観測されたが、発生原因は未確認であり、BLOG-0001側の障害と断定しない。

## 結果・判断
1. Blogger側のカスタムリダイレクト設定は変更しない。
2. BLOG-0001のGSC Redirect errorは「保留／経過観察する問題」として現在状態に残す。
3. 数日〜1週間後にGSCで、Redirect errorの解消・インデックス登録状況を再確認する。
4. 改善しない場合のみ、その時点の新しい一次情報を使って次の調査を判断する。

## 未確認
- `google.com/sorry/` HTTP 429の原因。
- GSC Redirect errorが`?m=1`だけで発生していることの完全な因果関係。

## 再利用上の注意
同じ調査を理由なく繰り返さず、次回はGSCの新しい状態変化を起点にする。
