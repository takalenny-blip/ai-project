# EXP-0000000060

## タイトル
VAIO P上の直チャット検索は実行できるが、GitHub Contents APIの大量取得でレート制限に到達する

## 内容
2026-09-14、VAIO P上のローカルclone `ai-project` で `python3 scripts/search_direct_chat.py chromium` を実行した。

初回実行では直チャットの内容が実際に出力され、検索スクリプト自体がVAIO P上で動作し、GitHubへの通信も成立していることを確認した。

再実行では `403 rate limit exceeded` が発生した。原因は、`scripts/search_direct_chat.py` がGitHub Contents APIを使い、`直チャット/` の一覧取得後に各ファイルを個別取得する実装であるため、APIリクエスト数が多くなり、未認証APIのレート制限に到達したことと判断した。

## 確認済み
- VAIO Pのローカルclone `ai-project` が存在する。
- Git 2.39.5 が利用可能。
- `scripts/search_direct_chat.py` はVAIO P上で実行できる。
- `chromium` 検索で直チャット内容が実際に出力された。
- 再実行時の失敗は `403 rate limit exceeded`。
- したがって、今回の失敗はVAIO PやPythonの実行不能ではなく、GitHub API利用方式の問題。

## 判断
現在の `scripts/search_direct_chat.py` を同じ条件で繰り返し実行しない。
ローカルcloneが既に存在するため、次回はGitHub APIを大量に叩かず、ローカルファイルまたはGitを使って直チャットを検索できる方式へ切り替える方向を採用する。
