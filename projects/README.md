# 取り組み一覧

ここは「運用ルール」ではなく、たかが実際に進めている・進めてきた取り組みを把握するための入口。

## 現在・継続して重要な取り組み

### VAIO P運用環境

VAIO Pを今後の自動化の実運用基盤として整備する。詳細は [`projects/VAIO_P運用基盤.md`](./VAIO_P運用基盤.md)。

### DIGA自動化

DIGA録画管理を発展させる取り組み。詳細は [`projects/DIGA自動化.md`](./DIGA自動化.md)。

特に、**お気に入り・機種別制御・警告メール**は、今後VAIO Pで自動化を進める重要テーマとして扱う。

## 過去に実施した主な取り組み

- DIGA録画管理
- 新譜通知GAS v2
- 見守りメール
- 眼科受診リマインド
- Firefox ESR軽量化
- VAIO P運用環境の過去作業

これらのうち、Claudeを使って行ったものがある。ただし、それは作業履歴であり、Claudeを現在の固定的な実装担当とするものではない。

## 経験DB

経験DB・直チャット記録基盤も、このプロジェクト自体を支える重要な取り組みとして継続する。

## 分類上の注意

「画像を補助記録として扱う」は取り組みではない。現在有効な運用ルールとして `rules/` で扱う。

「Claudeを使った」「JUNと作業した」は取り組みの分類ではなく、個々の作業に付随する履歴・実績情報として扱う。

## 現在の基本モデル

**たかが中心、バドが協働。**

JUN・Claude・その他のAI・ツールは必要に応じて使う補助手段であり、固定役割ではない。

詳細なプロジェクト資料は、今後必要になったテーマから追加する。
