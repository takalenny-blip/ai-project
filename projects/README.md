# 取り組み一覧

ここは「運用ルール」ではなく、たかが実際に進めている・進めてきた取り組みを把握するための入口。

## 現在・継続して重要な取り組み

### DIGA自動化

DIGA録画管理を発展させる取り組み。現在は現在状態正本と再開ガードを基準に、実行環境を固定せず段階的に進める。詳細は [`projects/DIGA自動化.md`](./DIGA自動化.md)。

特に、お気に入り・機種別制御・警告メールは継続テーマとして扱う。過去の環境依存手順は現在の作業手順には自動昇格させない。

### 現在状態・再開基盤

`docs/現在状態.json` を現在状態の正本とし、生成ビューと再開ガードで現在の実行環境・現在地点・次の一手を機械検証する。

### 過去環境の記録

過去環境の詳細は履歴資料として保持する。過去の環境依存手順は現在の作業手順へ自動昇格させない。

## セッション引き継ぎ

現在進行中の作業を次のチャットへ渡すための状態票は、`docs/引き継ぎ/現在の引き継ぎ.md` にある。

作業を再開するときは、対象プロジェクト資料だけでなく、この引き継ぎを確認してから具体的な操作へ進む。

## 過去に実施した主な取り組み

- DIGA録画管理
- 新譜通知GAS v2
- 見守りメール
- 眼科受診リマインド
- Firefox ESR軽量化
- 過去環境運用の過去作業

これらのうち、Claudeを使って行ったものがある。ただし、それは作業履歴であり、Claudeを現在の固定的な実装担当とするものではない。

## 経験DB

経験DB・直チャット記録基盤も、このプロジェクト自体を支える重要な取り組みとして継続する。

## 分類上の注意

「画像を補助記録として扱う」は取り組みではない。現在有効な運用ルールとして `rules/` で扱う。

「Claudeを使った」「JUNと作業した」は取り組みの分類ではなく、個々の作業に付随する履歴・実績情報として扱う。

## 現在の基本モデル

**たかが中心、バドが協働。**

JUN・Claude・その他のAI・ツールは必要に応じて使う補助手段であり、固定役割ではない。

詳細なプロジェクト資料は、今後必要になったテーマから追加する。
