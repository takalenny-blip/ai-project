## 1. 構成の基本方針

- 冒頭はエピソード6のパルパティーンの最期から始める案。
- 死を契機にバックアップ／再生システムが動き出す様子を、暗い画面・短いカットで機械的に示す。
- 冒頭で敵の軍事計画、艦隊、兵器、AIの全容を説明しない。長い説明や詳細なプロローグにはしない。
- 物語の中心は共和国側、ハンとレイアの家族、ベン、ルークへ移す。
- 子パルの正体は冒頭から観客に明かす方向を候補とする。ただし、開示方法・タイミングは最終確定ではない。
- 第1段階の時系列と、観客に見せる順番を混同しない。

## 2. 観客に見せる順番（構成案）

### プロローグ：パルパティーンの死と再生システム

1. エピソード6でパルパティーンが死亡する。
2. 暗い施設内でシステムが起動し、クローンの製造・記憶データの転送が始まる。
3. 無人機械が淡々と動き始める。説明台詞は極力置かず、短く機械的に示す。
4. ここでは敵の全体像や計画の詳細を説明しない。

### 第1部：共和国とベンの幼少期

1. 新共和国の時代。ハンとレイア、家族の状況を描く。
2. ベンは強いフォースを持つが、幼い頃は制御できず、感情が表に出ると周囲を傷つけてしまう。
3. ベンが苦しみ、家族も対応に悩む。
4. ハンとレイアは、修行によってベンが力を制御できるようになることを期待し、ルークのもとへ送り出す。
5. ベンの年齢は現時点の目安として約10歳。確定年齢ではない。

### 第2部：子パルの出現と孤児院の火事

1. ベンがルークのもとへ行く出来事を、子パルがフォースで感知する。
2. その出来事を感知した後、クローンのカプセルが開き、子パルが現れる。
3. 子パルの身体年齢はベンと同じとする。現時点の目安は約10歳。
4. 子パルは孤児院で火事を起こし、その火事から皆を助ける。
5. 子パルは「奇跡の子」として知られるようになり、ルークが発見するきっかけとなる。
6. ルークは子パルをジェダイ聖堂へ連れて行く。
7. 観客には子パルの正体を早い段階で知らせる案を基本候補とする。登場人物がいつ正体を知るかは別に扱う。

### 第3部：子パルとベン、魔石

1. 子パルはジェダイ聖堂でベンに近づく。
2. ベンが感情を隠さず表に出し、周囲の人を傷つけてしまう場面で、子パルは魔石を使ってベンに接近する。
3. 魔石はベンのダークフォースを吸収し、ベンに一時的な安心を与える。
4. 魔石は吸収に伴って透明から黒く変化していく。
5. 子パルはやがて聖堂から姿を消す。その後もベンの頭の中へイメージを送る形で接触を続ける。

### 第4部：魔石の限界とルークの自己犠牲

1. ルークはベンの異変に気づき、ヨーダに相談する。
2. 魔石が限界に近づき、ベンの危機が深まる。
3. ルークはベンを救うため、あえてベンを攻撃するふりをする。
4. 魔石が割れ、蓄積されたダークフォースが放出される。
5. ルークはベンへ向かう暗黒の力を自分に引き受ける。
6. ベンはライトサイドに留まり、ルークは暗黒の力を抱えたまま苦しむ。

### 第5部：ルークの潜入とベンの修行

1. ルークは暗黒の力に苦しむ状態を利用し、子パル側に自分が暗黒面へ堕ちたと思わせる。
2. ルークは敵側へ潜入し、施設・基地・データセンター・AIに関する情報を探る。
3. ベンはヨーダのもとで修行し、フォースの制御と精神的な強さを身につける。
4. ルークとベンには特別なフォースのつながりが生まれ、情報を伝え合う方向。
5. ルークが子パルの正体や異常さを問いただす場面は、この段階の早い時期には置かない。物語の最後の最後に置く。

### 第6部：情報入手、共和国軍基地での合流、救出計画

1. ルークは敵施設のネットワーク構成、施設の位置、データセンター関連情報などを得る。
2. ルークが情報を転送したことをAIが監視し、パルパティーン側へ報告する。
3. ベンはルーク救出を決意する。
4. ベンたちは救出に出発する前に、まず共和国軍の基地へ合流する。
5. 基地で敵施設の位置や設計図などの情報を受け取る。R2-D2が情報面で重要な役割を担う。
6. そこで救出作戦と施設破壊作戦を立案する。

### 第7部：敵施設への作戦

1. ベンとR2-D2が施設へ接近・潜入し、R2-D2がベンをルークのもとへ導く。
2. ベンがルークを救出する。
3. ルークとベンは協力して敵側と対決する。「コパル」と子パルの関係は未決。
4. R2-D2は二人の救出後、別行動に移る。
5. ハンとチューバッカは施設に爆弾を設置し、R2-D2の端末接続とウイルス投入を支援する。
6. ウイルスによって周辺AIの制御が崩れ、バックアップがデータセンター側へ集中する。
7. データセンター側の処理負荷が高まり、敵の統制・兵器制御に異常が生じる。
8. 共和国軍がその機会に反撃する。
9. C-3POがミレニアム・ファルコンを操縦して一行を迎え、全員が脱出する。
10. 脱出後に爆弾が作動し、敵施設・クローン施設が破壊される。

### エピローグ：残るデータセンター

1. 敵施設は破壊されるが、別の場所にあるデータセンター本体は残る方向。
2. データセンターでは次のクローン作成・記憶転送が始まる可能性がある。
3. 共和国側はデータセンターの所在地を特定できていない。
4. 物語の最後の最後に、ルークが子パルを問いただす場面を置く案。問いただす内容・場面の具体的な位置づけは未決。

## 4. 最新の判断として優先する事項

- ベンと子パルは同じ年齢。
- 子パルが感知するのは、ベンがルークのもとへ行く出来事。感知手段はフォース。
- 子パルはその出来事を感知した後、カプセルから現れる。感知と覚醒の細かな仕組みは未決。
- 孤児院では子パルが火事を起こし、皆を助ける。
- ベンが感情を表に出し、周囲の人を傷つけてしまう場面で、子パルが魔石を使って近づく。
- ルークが子パルを問いただすのは物語の最後の最後。
- ベンがルーク救出へ向かう前に、共和国軍基地で合流し、施設情報・設計図を得てから作戦を立てる。
- プロローグは暗く短く、機械的な進行を示すだけにする。長い説明をしない。
