# 観客向け構成・第2段階（再構築案）

- 対象：スター・ウォーズ続編再構築
- 目的：物語世界の時系列を踏まえ、観客に見せる順番と情報の開示順を整理する。
- 状態：再構築した構成案。確定脚本・完成絵コンテではない。未決事項は確定しない。
- 更新日：2026-11-10
- 注意：物語世界の時系列と、観客に見せる順番を混同しない。既決事項と未決事項を区別する。

## 1. 構成の基本方針

- 物語の中心は、パルパティーン復活の謎、帝国残党の再建、ベンとルークの関係、共和国側の対応である。
- パルパティーンはエピソード6で一度死亡している。単純に生き延びていたことにはしない。
- パルパティーンが復活した可能性を早い段階で提示するが、なぜ復活できたのか、その仕組みはすぐには明かさない。
- 帝国軍の残党が再び帝国を築こうとしていることも、前半から少しずつ示す。
- 敵の拠点の調査は共和国側で進める。ルークが拠点を探すために敵側へ弟子入りする構成にはしない。
- ルークが暗黒面へ堕ちるのは本当の転落であり、演技・偽装ではない。強靱な精神力で自我と使命を保つ。
- ルークがパルパティーンの弟子になる理由は、パルパティーンが復活できた仕組みを解明することに絞る。
- 読者にすべての情報を一度に説明しない。登場人物と読者の知る情報に差を残し、謎を段階的に明らかにする。

## 2. 観客に見せる順番（再構築案）

### プロローグ：パルパティーンの死と、何かが動き出す気配

1. エピソード6でパルパティーンが死亡する。
2. 暗い施設内で、何らかのシステムが起動する。
3. カプセルや機械、データの転送を思わせる断片を短く見せる案。ただし、何が作られ、何が保存されているのかを説明しきらない。
4. 敵の軍事計画、クローン、データセンターの関係など、全体像は伏せる。
5. 長い説明台詞は置かず、観客に疑問を残して本編へ移る。

### 第1部：新共和国とベンの幼少期

1. 新共和国の時代。ハンとレイア、家族の状況を描く。
2. ベンは強いフォースを持つが、幼い頃は制御できず、感情が表に出ると周囲を傷つけてしまう。
3. ベンが苦しみ、家族も対応に悩む。
4. ハンとレイアは、修行によってベンが力を制御できるようになることを期待し、ルークのもとへ送り出す。
5. ベンの年齢は現時点の目安として約10歳。確定年齢ではない。

### 第2部：子パルの出現と孤児院の火事

1. ベンがルークのもとへ行く出来事を、子パルがフォースで感知する。
2. その出来事を感知した後、クローンのカプセルが開き、子パルが現れる。
3. 子パルの身体年齢はベンと同じとする。現時点の目安は約10歳。
4. 子パルは孤児院で火事を起こし、その火事から皆を助ける。
5. 子パルは「奇跡の子」として知られるようになり、ルークが発見するきっかけとなる。
6. ルークは子パルをジェダイ聖堂へ連れて行く。
7. 観客には子パルの正体を早い段階で知らせる案を維持する。ただし、登場人物がいつ正体を知るかは別に扱う。

### 第3部：子パルとベン、魔石

1. 子パルはジェダイ聖堂でベンに近づく。
2. ベンが感情を表に出し、周囲の人を傷つけてしまう場面で、子パルは魔石を使ってベンに接近する。
3. 魔石はベンのダークフォースを吸収し、ベンに一時的な安心を与える。
4. 魔石は吸収に伴って、白から灰色、黒、赤へと変化していく。
5. 子パルはやがて聖堂から姿を消す。その後もベンの頭の中へイメージを送る形で接触を続ける。
6. ベンが魔石を持っている可能性が浮上し、ルークはその異変を確かめようとする。

### 第4部：ヨーダとの会話、魔石の危険、パルパティーン復活の疑い

1. ルークは、ベンが魔石を持っているのではないかとヨーダに相談する。
2. まず、ベンが実際に魔石を持っているかどうかを確かめる必要があると整理する。所持を確認する前に、色の確認や感知へ進まない。
3. ベンが魔石を持っていた場合、ルークはその色を確認する。
4. ヨーダは、魔石の色が白 → 灰色 → 黒 → 赤と変化すること、黒に近づいた段階では元に戻せなくなること、赤は砕ける寸前であることを説明する。
5. 魔石が黒に近づいた段階ではフォースを通じて存在を感知できる。この性質をヨーダはルークに事前に伝える。
6. ヨーダは、過去に魔石を使った者たちに悲劇が起きたことも伝える。具体的な事例は未決。
7. この会話の中で、「パルパティーンは復活したのかもしれない」「なぜ復活できたのかを解明できなければシスを倒せない」という趣旨を提示する。
8. ただし、復活の具体的な仕組みや敵の全貌を、読者にすべて説明しない。可能性と謎を残す。

### 第5部：共和国側が察知する帝国残党の再建準備

1. 帝国軍の残党が、再び勢力を取り戻し、帝国を再建する準備を進めていることが明らかになっていく。
2. レイアは共和国側から得た情報と、その時点での調査状況をルークに伝える。
3. 敵の拠点の場所や軍事施設の全容は、まだ分からない。
4. 拠点の捜索・調査は共和国側が進める。ルーク自身が拠点を探す必要はない。
5. 共和国側の調査で新しい情報が得られたら、レイアがルークに状況を伝える。
6. この段階では、帝国残党の再建準備とパルパティーン復活の謎が並行して存在するが、両者の全体像はまだ明かさない。

### 第6部：ベンの危機とルークの自己犠牲

1. ベンへの心理操作や魔石の影響が深まり、ベンの危機が大きくなる。
2. トリの死、いじめグループ、ベンの怒りをめぐる展開を置く案がある。具体的な場面順・状況は未確定。
3. ベンの怒りが高まり、魔石は破壊寸前の状態へ進む。
4. ルークはベンを守るため、魔石に蓄積された暗黒の力を自分へ引き受ける。
5. ルークが暗黒の力を引き受けた後、魔石は砕ける。
6. ルークは本当に暗黒面へ堕ちる。これは演技や偽装ではない。
7. ルークは強靱な精神力で自我と使命を保つ。
8. ベンは、自分を守った代償でルークが変わってしまったことに罪悪感を抱き、ルークを救いたいと願う。

### 第7部：ルークの弟子入りと、復活の仕組みの解明

1. ルークはパルパティーンの弟子になる。
2. ルークが弟子入りする目的は、パルパティーンがなぜ、どのような仕組みで復活できたのかを解明することに絞る。
3. ルークは本当に暗黒面へ堕ちている。暗黒面への転落を装ったり、子パルに堕ちたと思わせるために演技したりする展開にはしない。
4. ルークは強靱な精神力で自我と使命を保ち、弟子としてパルパティーンのそばにいる。
5. 子パルはルークの力を利用しようとする。その思惑が、ルークを弟子として受け入れる理由の一つになる可能性がある。
6. ルークは弟子として接する中で、パルパティーン復活の仕組みを解明しようとする。具体的に何を知り、どう理解するかは未決。
7. 敵拠点の調査は共和国側の役割であり、ルークの弟子入りの目的には含めない。

### 第8部：ベンの修行とルーク救出への決意

1. ベンはヨーダのもとで修行し、フォースの制御と精神的な強さを身につける。
2. ベンは、ルークが自分を守るために犠牲を払ったことを知る。
3. ベンは罪悪感を抱きながらも、ルークを救いたいという自分の意思を固める。
4. ルークとベンの間に生まれた特別なフォースのつながりを、救出や情報伝達にどう用いるかは未決。便利な通信手段として無制限に扱わない。
5. ベンは必要な情報をレイアや共和国側につなぐ方向を検討する。

### 第9部：最終作戦と役割分担

1. ルークとベンは、パルパティーン／シスとの直接対決を担う。
2. ハン、レイアたちの別働隊は、パルパティーンの復活を支えるクローン施設やデータセンターなどの破壊を担う方向。
3. 共和国軍は、敵艦隊・AI軍事システムなどに対する軍事作戦を担う。
4. 共和国側の拠点調査で得られた情報、ルークが弟子として解明した復活の仕組み、ベンたちが得た情報を、必要な範囲で作戦に結びつける。
5. 各作戦の具体的な開始時刻、連携方法、施設の場所、破壊対象の優先順位は未決。

### エピローグ：残るデータセンターの可能性

1. クローン施設とデータセンター本体は別の場所にある方向。
2. クローン施設を破壊しても、データセンター本体が残る可能性がある。
3. データセンターには、パルパティーンの記憶・経験・知識が保存されている構想。
4. データセンター本体の所在地や、破壊後に何が残るかは未決。結末でどこまで明かすかも検討する。

## 3. 情報開示の基本ルール

- **読者に早めに見せる候補：** パルパティーンの死後に何かが動き出したこと、子パルの正体、帝国残党が再建準備をしている兆候。
- **登場人物より読者が先に知る可能性がある情報：** 子パルの正体や、パルパティーンの再生に関係する断片。ただし、全容を理解できる情報は与えない。
- **登場人物と読者の双方に謎として残す情報：** パルパティーンが復活できた具体的な仕組み、敵拠点の正確な場所、クローン施設とデータセンターの全体像。
- **ヨーダの会話で示す情報：** パルパティーン復活の可能性と、仕組みを解明しなければシスを倒せないという問題。詳細は伏せる。
- **レイアから伝わる情報：** 共和国が把握している帝国残党の動きと、拠点調査の進展。未確認のことは未確認のまま伝える。
