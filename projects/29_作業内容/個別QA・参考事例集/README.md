# 個別QA・参考事例集

AIとの作業で生じた疑問、もどかしさ、工夫、解決策を、他の人も参考にできる事例として蓄積する。

## この場所の役割

- 個別の問いと、その背景にある課題を残す。
- たか自身の発想・判断と、AIが支援した整理・実装を区別する。
- 実際に行ったことと、未検証・未決のことを分ける。
- 他の人が自分の環境へ応用するときのヒントを示す。

ここにある事例は、共通ルールや完成済みの標準手順ではない。環境や目的に応じて異なる解決方法があり得ることを前提とする。

## 記録の基本項目

1. きっかけ・問題
2. 問い・試行錯誤
3. 発想・解決策（誰が発想したかを含む）
4. 実装内容
5. 結果・検証状況
6. 残る課題・限界
7. 他の環境へ応用するときのヒント

必要な項目だけを使い、形式を埋めること自体を目的にしない。
