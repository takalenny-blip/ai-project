# 29_作業内容

AIとの共同作業で生まれた個別QA、問題解決の試行錯誤、実装例を蓄積する領域。

## 現在の保存先

- [個別QA・参考事例集](./個別QA・参考事例集/README.md)

## 運用方針

- 事例は、発生した問題・本人の発想・検討・実装・確認結果を分けて記録する。
- 事例の内容を、すべての利用者・プロジェクトに共通する正解として扱わない。
- 他の環境へ応用するときは、目的・制約・既存ルールに合わせて読み替える。
- note等で公開する場合は、事例の蓄積とは別工程として企画・確認する。公開・販売を自動的に決定しない。
- 直チャット原本や既存の記録を、事例化を理由に変更・削除・改名・上書き・置換しない。
