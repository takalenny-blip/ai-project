# VAIO P運用基盤

更新日：2026-09-07

## 1. 位置づけ

VAIO Type Pは、単なるDebian環境ではなく、今後の自動化を継続稼働させるための**実運用基盤**として整備する。

## 2. 現在地

- Debianの基盤構築まで進んでいる。
- 今後、定期実行・データ処理・ログ・エラー処理・GitHub連携などを必要な順に整備する。
- 実機の現在値は `docs/VAIOP現状台帳_2026-09-07.md` を参照する。
- 過去の推測値と現在確認済みの値を混同しない。

## 3. 共通基盤として整備する候補

- 自動実行・スケジュール実行
- Python等の実行環境
- プログラム・データ・ログの配置ルール
- エラー記録・通知
- GitHubとの連携
- バックアップ
- 稼働状況の確認
- 複数の自動化を安全に共存させる仕組み

最初から全部を作らず、実際に使う自動化に必要なものから整備する。

## 4. 最初の実運用対象

DIGA自動化を最初の主要な実運用対象とする。

特に、DIGA予約情報の自動取得を入口として、録画管理・お気に入り・機種別制御・警告メールへ段階的につなげる。

## 5. 基本構成の考え方

```text
VAIO P
  ├─ 情報取得
  ├─ データ処理
  ├─ 定期実行
  ├─ ローカルログ
  └─ 必要な監視
          ↓
Google Drive / Sheets / GAS等
  ├─ データ管理
  ├─ 通知
  ├─ Web画面・フォーム等
  └─ 人が確認・操作する部分
```

この境界は固定せず、実装・テストを通じて決定する。

## 6. 運用記録

VAIO Pで実際に行った作業は、コマンド、入力、出力、エラー、設定値、結果などを可能な限りテキストで直チャットへ残す。

画像は物理状態・外観・画面状態などを補助する場合に使う。画像だけを重要事実の一次記録にしない。

実際の問題、判断、修正、成功、失敗は必要に応じてEXP/RECへ整理する。
