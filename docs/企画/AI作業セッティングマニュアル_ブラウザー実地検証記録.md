# AI作業セッティングマニュアル：ブラウザー実地検証記録

## 目的

ChatGPTチャットをMarkdownで保存する候補について、公開情報の確認と、実際にブラウザーで操作した結果を分けて記録する。公開情報を読んだだけでは、実地検証済みとしない。

## 実施前の安全確認

- [ ] テスト用会話に個人情報、認証情報、Cookie、トークン、非公開情報が含まれていない。
- [ ] Chrome ウェブストアの開発者名、更新日、権限、プライバシー開示を読み直した。
- [ ] 権限の範囲とデータの扱いを理解できた。理解できない場合は導入を保留し、手動コピーを使う。
- [ ] 「ファイルを保存できた」ことを「外部送信がない証明」と誤認しない。

## テスト手順

1. 機密情報を含まない短いテスト会話を開く。日本語、見出し、箇条書き、コードブロック、リンクを含める。
2. 拡張機能のメニューからMarkdown形式で保存する。画面の文言が異なる場合は、実際の表示を記録し、推測で操作しない。
3. 保存した .md ファイルをテキストエディターで開く。
4. 次のチェック表を記録する。
5. 問題があれば再現条件と実際の結果を記録し、合格扱いにせず、手動コピーへ切り替える。
