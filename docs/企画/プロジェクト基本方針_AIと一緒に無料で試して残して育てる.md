# プロジェクトの基本方針
## AIと一緒に。無料で試して、残して、育てる。

- 状態：基本方針（理念・制作判断の基準）
- 対象：ブログ、note、AI作業セッティングマニュアル、および今後の関連コンテンツ

## 1. このプロジェクトで実現したいこと

AIを使って何かを始めたい人が、お金や知識の不足、一人で取り組む難しさを理由に諦めず、自分にできることから挑戦できるようにする。

AIと一緒に試行錯誤し、「自分にもできた！」という発見やワクワクを体験できる人を増やす。

## 2. 前面に押し出す二つの強み

### 無料で始められる

高価な道具や完璧な準備がなくても、無料で利用できるサービスなどを活用して、できることから始められる。無料プランの上限や機能差など、実際の制約は正直に伝える。

### 一人でやらなくていい

分からないことはAIに相談できる。考えを整理し、手順を考え、問題を一緒に解決しながら、自分の環境に合わせて進められる。AIが代わりに操作できない場面や、回答を実際に確認する必要があることも隠さず伝える。

「無料」「AIが便利」と言うだけでなく、何を無料で試せるのか、AIにどう手伝ってもらえるのかを具体的に示す。

## 3. 有料マニュアルの位置づけ（決定事項）

**AI作業セッティングマニュアルは有料で提供する。** 有料で提供することは決定済みであり、今後の検討で未決事項に戻さない。

有料にするのは、たか自身が経験した貴重な試行錯誤や発見、実践方法には、お金を生み出す価値があると確信しているため。その経験をほかの人にもお裾分けし、同じようなワクワクを体験してほしいという思いを、読者に率直に伝える。

マニュアルは知識を並べただけの説明書ではなく、**AIに相談しながら、自分専用のAI作業環境を一緒に作っていくためのガイド**を目指す。有料マニュアルは、その体験に踏み込むための入場料という感覚で届ける。

有料で提供することは決定済み。価格、販売プラットフォーム、提供形式、公開時期などの具体的条件は別途決定する。無料で始められることと、マニュアル自体が無料であることは明確に区別する。

## 4. コンテンツそれぞれの役割

- **ブログ：** 実際に試したこと、失敗、発見、考えたことを共有し、読者が「自分もやってみたい」と思える入口を作る。
- **note：** 読者が挑戦するときに役立つ情報や具体的な実践内容を届ける。マニュアルへの案内は、読者がさらに深く取り組みたいと思ったときの自然な導線として添える。noteを販売案内だけの場所にしない。
- **有料マニュアル：** AIと対話しながら、自分専用の作業環境を作っていく具体的な体験を支える。

それぞれの役割を生かしながら、一つの体験につながるように整える。

## 5. 「試して、残して、育てる」の意味

試して得た経験を残し、それを次の挑戦に生かす。AIとのやりとりも、作った環境も、経験を重ねながら自分に合ったものへ発展させていく。試して終わりにせず、経験を次の可能性につなげる。

## 6. 制作で大切にすること

- 読者の「やってみたい」という気持ちを大切にする。
- 無料で始められる方法を、具体的に示す。
- AIに手伝ってもらいながら進める様子を、実例を通して伝える。
- 失敗や試行錯誤も、次に生かせる経験として残す。
- 読者が自分の環境やペースに合わせて挑戦できるようにする。
- 体験の楽しさや価値を伝えるが、結果や効果を保証する表現は避ける。
- 管理や仕組みの整備は、作りたいものを作り続けるために行う。管理そのものを目的にしない。
- 決定事項と未決事項を区別し、未決事項を理由に依存しない作業全体を止めない。

## 7. 判断に迷ったときの原点

「お金がないから諦める」を減らす。
「一人では難しいから諦める」も減らす。
そして、自分にもできたというワクワクを、もっと多くの人に届ける。

**管理しやすいものを作るんじゃない。作りたいものを、ちゃんと作り続けられるように管理する。**
