# AI作業環境構築・完了チェックリスト

このチェックリストは、マニュアルと伴走プロンプトを使って作業環境を整えたあと、実際に確認できたことを記録するためのものです。すべての項目を一律に満たす必要はありません。自分が選んだ構成に該当する項目だけを確認し、実施していない項目はチェックしないでください。

## 進行フローの確認

チェックリストは、伴走プロンプトの代わりに手順を案内する資料ではなく、各段階で実際にできたことを確認するための資料です。

- [ ] **開始準備：** マニュアル本文と伴走プロンプトをAIに渡し、読み込めた範囲を確認した。
- [ ] **目的と構成：** 第1章を使って目的を決め、最小構成／標準構成を選んだ。
- [ ] **基本環境：** 第2章を使ってAIの利用準備と安全上の注意を確認した。
- [ ] **必要な仕組み：** 必要な場合だけ、第3〜5章から使う仕組みを選んだ。不要な仕組みは追加していない。
- [ ] **練習：** 第6章でプロンプトを作って試した。経験があり省略した場合は、その理由をメモした。
- [ ] **本番：** 第7章で実際のテーマを試し、結果を確認して記録した。
- [ ] **完了確認：** 実際に確認できたこと、未完了・未確認のこと、次に行うことを整理した。

ここで未チェックの項目があっても、ただちに失敗という意味ではありません。選んだ構成に不要な項目は対象外とし、必要な項目が未完了なら最終判定にそのまま記載してください。

## 1. 最小構成：AIを使って試し、結果を残す

- [ ] 今回実現したいことと、最初に試す小さな作業を決めた。
- [ ] 使用するAIを選び、必要な機能・利用条件を確認した。
- [ ] AIサービスにログインし、機密情報を含まない内容で会話できた。
- [ ] AIに渡してはいけない秘密情報（パスワード、認証コード、トークン等）を理解した。
- [ ] AIの案内に沿って小さな作業を実行し、結果を自分で確認した。
- [ ] 結果をテキストファイルや使い慣れたメモアプリに保存した。
- [ ] 保存したファイルを開き直し、必要な内容が残っていることを確認した。
- [ ] できたこと、未確認のこと、次に行うことを整理した。

### Dropbox

- [ ] 管理表や記録に秘密情報・不要な個人情報を入れていない。

## 判定のルール

- 実行して結果を確認した項目だけにチェックを付けます。
- AIが「できた」と答えたことだけではチェックを付けません。
- 未確認の項目が残っている場合は、その内容を明記し、全体を「一部完了」または「未完了」とします。
- 最小構成で目的を達成できているなら、GitHub・拡張機能・Dropboxなどを無理に追加する必要はありません。
