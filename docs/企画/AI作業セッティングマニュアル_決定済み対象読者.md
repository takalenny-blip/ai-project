# AI作業のセッティングマニュアル：決定済み対象読者・基本方針

- 状態：**決定済み・再検討禁止**
- 管理責任：本ファイルを対象読者と基本方針の正本とし、構想メモ・作業キュー・引き継ぎは本ファイルを参照する。
- 適用対象：セッティングマニュアル本文、章構成、無料サンプル、公開準備、関連する制作判断。

## 決定済みの対象読者・方向性

- AIでいろいろ試したい人
- AIとの作業で得た経験を蓄積し、できれば公開したい人
- 「AIを使って何かできないかな？」と考えている人
- 生成AIの利用から仕組み作り、公開まで、**無料でできることを大前提**とする。

この4項目は、たかが決定した基本方針である。制作工程が変わったこと、チャットが変わったこと、章別設計が完了したこと、作業キューを整理したことを理由に、未決定へ戻したり、再び対象読者を絞る作業を要求したりしてはならない。

## 変更管理

1. 制作開始・再開時に、まず本ファイルを読み、本文・構成案が4項目に沿っているか確認する。
2. 本文執筆・章構成変更・公開範囲決定の前に、本ファイルとの整合を確認する。整合が確認できない草稿は確定稿として扱わない。
3. 対象読者・基本方針の変更が必要だと考えた場合、AIが独断で変更せず、変更案・理由・影響範囲をたかへ提示して明示的な承認を得る。
4. 承認後にのみ本ファイルを更新し、関連する構想メモ、`docs/現在状態.json` の作業工程、生成ビュー（`BUD.md` と `docs/引き継ぎ/現在の引き継ぎ.md`）を同じ変更単位で同期する。
5. 「対象読者と困りごとを絞る」を未完了工程として残さない。最初に解決する困りごとなど、対象読者とは別の論点が本当に未決定の場合は、その論点だけを分離して記録し、対象読者の決定を巻き戻さない。
6. 各章の完成確認では、対象読者・無料前提との整合をチェック項目に含める。

## 作業再開時の必須チェック

- [ ] このファイルを読んだ
- [ ] 対象読者・基本方針を未決定として扱っていない
- [ ] 本文・構成が決定済み方針と矛盾していない
- [ ] 方針を変える場合は、たかの明示的承認を得ている

**完了条件：** 新しいチャット・工程・担当AIへ移っても、決定済みの対象読者と無料前提を再検討に戻さず、すべての制作成果物で整合性を確認できる。
