## 今度はWi-Fi

Debianが起動した。

次はネットワークだ。

ところが、今度はWi-Fiにつながらない。

「え？また？まじかよー」

フロントのワイヤレスランプもつかない。

「なんでランプつかないんだー」

またバドに相談する。

まず状態を確認する。

```
rfkill list
```

次にネットワークインターフェースを見る。

```
ip link
```

NetworkManagerも入れて、

```
sudo nmtui
```

を開いてみる。

でも、Wi-Fiが見えない。

有線でつないでみようかと思っても、このVAIO PにはLANの口がない。

ここでも、また一つずつ試していく。

iPhoneのUSBテザリングも使いながら、必要なものを入れていく。

調べていくと、どうも無線LANそのものが壊れているわけではなさそうだった。

最終的には、/etc/network/interfaces に残っていた無線LANの設定がNetworkManagerの管理を邪魔していた。

そこを修正して、NetworkManagerを再起動する。

```
sudo systemctl restart NetworkManager
```

すると、

おお、ついた！

ワイヤレスランプが点いた。

Wi-Fiも見えるようになった。

最後に、

```
ping -c 3 8.8.8.8
```

で確認。

「オケ」

つながった。
