# BLOG-0003 重要事項統合台帳 v01

## 目的
BLOG-0003の一次資料調査で拾った重要事項を、本文とは分離して再利用できる形にする。
これは完成原稿ではなく、時系列・因果・再利用先を追跡するための作業台帳。

## 読み方
- 確認済み：一次資料またはGitHub上の実体で確認できたもの
- 関連確認：コミット/PR等で事実関係は確認できるが、会話本文との因果が未確定
- 未確認：本文採用前に一次資料本文の追加確認が必要
- 本文採用はこの台帳から自動決定しない。一次資料→採用判断を分離する。

## 再利用ルール
- 本文を書くときは、この台帳から発言を直接引用しない。必ず元の一次資料へ戻る。
- 「確認済み」と「関連確認」を混ぜない。
- 技術項目は単独で説明せず、「何が困った→何を変えた」と結び付ける。
- 後から新資料が見つかった場合は、該当日時へ追加し、既存項目を書き換えて歴史を平坦化しない。
- 本文採用済みになった項目には、採用先の章を追記できる。
