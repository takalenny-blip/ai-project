# AIと一緒に、できることを増やす

AIとのやりとりを、会話だけで終わらせない。

試したことや決めたことを残し、次の作業に活かす。経験を重ねるほど、自分に合う方法へ育てていく。

そんな使い方ができたら、AIとの会話は、その場限りの相談ではなく、次の挑戦につながるものになる。

そのための仕組みを、一人で一から調べて作るのは簡単ではない。何を準備すればいいのか、どの順番で進めればいいのか。分からないことが出てくるたびに、手が止まってしまうこともある。

そこで、AIに進め方のノウハウを読み込ませ、相談しながら自分に合う仕組みを作っていく方法を考えた。

## 実際に試してきたこと

私自身、AIとのやりとりを残し、試行錯誤を重ねながら、少しずつ作業に活かせる形を作ってきた。

## マニュアルをAIに渡すと、そこから対話が始まる

今回紹介する有料マニュアルは、単に人が読んで知識を得るための説明書ではない。

AIとどのように協力するか、何を確認してから進めるか、迷ったときにどう判断するか。そうした進め方やルールを、AIが参照できる形にまとめたものだ。

使い方のイメージはシンプルだ。

1. 有料マニュアルのファイルをダウンロードする。
2. ChatGPTなど、ファイルを読み込めるAIとのチャットに添付する。
3. AIがマニュアルの指示や進め方を読み取り、その方針に沿って対話を始める。
4. まず、あなたがAIを使って実現したいことを確認し、必要に応じて環境や進め方を一緒に整理する。

マニュアルの中から必要なプロンプトを探し、一つずつコピーして貼り付けることを前提にはしていない。最初に読むべき指示をマニュアル内に用意し、AIがそこから進められるようにしている。

ただし、ファイルの読み取り方や扱える範囲は、利用するAIや環境によって異なる。AIがマニュアルを十分に読めていない場合は、そのことを確認し、必要な対応を案内する。どのAIでも無条件に同じ動作を保証するものではない。

### 例えば、最初のやりとりはこんなイメージ

**AI：**
「マニュアルの進め方を確認しました。最初から設定変更やファイル作成を始めるのではなく、まず、あなたが実現したいことを起点に進めます。AIを使って、どんなことをできるようにしたいですか？」

**あなた：**
「毎日の作業を少し楽にしたい。自分でも使える仕組みを作ってみたい」

**AI：**
「分かりました。今の環境でできることから考えましょう。必要なことを整理したら、まずは具体案を出します。設定変更などが必要な場合は、内容を説明して相談してから進めます」

これは進め方を伝えるための例で、すべての会話が必ずこの文面になるという意味ではない。大切なのは、AIがいきなり作業を押しつけるのではなく、あなたの目的を確認し、それに合わせて一緒に進めることだ。

## 一人で全部を決めなくてもいい

何を作りたいのか、最初から細かく説明できなくても大丈夫だ。

「AIを使って何か始めたい」「作業を楽にしたい」「自分の経験を残して、あとで活用したい」。まずはそのくらいの希望から相談できる。

AIは、その話をもとに目的や方向性を整理し、必要な環境を確認しながら具体案を提案する。質問を続けた方がよい場面もあれば、見えてきた目的をもとに、早めに案を出して試してみる方がよい場面もある。

また、最初から有料サービスや複雑な設定を前提にしない。今ある環境や無料で使える方法を優先し、追加の仕組みが本当に必要かを確かめてから進める。

AIがすべてを正しく理解して、何もかも自動で完成させるわけではない。提案の確認や実際の操作、結果の判断は人が行う。それでも、進め方を共有したAIと相談しながら試せることは、一人で手探りを続けるときとの大きな違いになる。

## 作業の結果を残せば、次にもつながる

その場で問題が解決しても、やりとりや判断の理由が残っていなければ、次に同じことをするとき、また最初から説明し直すことになりかねない。

そこで、作業した内容だけでなく、決めたこと、まだ分からないこと、次にやることも整理して残していく。

そうすれば、新しいチャットで続きを相談するときにも、前回の成果や進捗を手がかりに再開しやすくなる。うまくいった方法も、失敗した方法も、次の作業に活かせる経験になる。

「試して終わり」ではなく、試したことを残し、次に使い、少しずつ育てていく。これが、このプロジェクトで大切にしている考え方だ。

## 有料マニュアルで目指している体験

このマニュアルには、AIと一緒に作業環境を構築するための考え方や手順、作業を進める際のルール、判断に迷ったときの考え方などをまとめている。

目指しているのは、マニュアルを読んで終わることではない。マニュアルをAIに渡し、AIと相談しながら、自分の目的に合う作業環境や進め方を一緒に形にしていくことだ。

最初の一歩を踏み出し、実際に試してみる。うまくいかなければ、状況を整理して修正する。できたことや分かったことを残し、次の挑戦に活かす。

一つできると、次にやってみたいことが見えてくるかもしれない。自分の仕事や活動に合わせて仕組みを工夫し、使いながら育てていくこともできる。

**「自分にもできた！」から、「次はこれをやってみたい！」へ。**

## AIと一緒に、できることを増やしていこう

最初から何でも知っている必要はない。完璧な計画を立ててから始める必要もない。

まずは無料でできることを試してみる。必要なことをAIと相談する。やってみた結果を残して、次に活かす。

AIと一緒に試して、残して、育てる。その繰り返しが、自分にできることを少しずつ増やしてくれるはずだ。
