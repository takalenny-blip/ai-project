# AIと一緒に、できることを増やす

AIとのやりとりを、会話だけで終わらせない。

作業の手順や決めたことを残し、次の作業に活かせる仕組みを作る。そうすれば、これまでの試行錯誤を次につなげられる。

そのための方法の一つが、GitHubなどの保存システムを活用することである。

ただし、仕組みを作るには、使い方を調べたり、手順を確認したりする必要がある。初めて取り組む人にとっては、そこが難しいところでもある。

そこで役立つのが、AIにノウハウを読み込ませ、対話しながら仕組みを作っていく方法である。

## 実際に試してきたこと

私自身、AIとのやりとりを残し、試行錯誤を重ねながら、少しずつ作業に活かせる形を作ってきた。

その過程で気づいたことや、実際に試したことをブログにまとめている。

**[ブログ記事はこちら](https://takalenny-blip.github.io/ai-project/)**

## AIと一緒なら、その先へ行ける

AIとのやりとりを残し、次の作業に活かす仕組みを作る。言葉にすれば簡単だが、実際に一人で始めようとすると、何から手をつければいいのか分からないこともある。

そんなとき、力になるのが、私自身の試行錯誤から得たノウハウを凝縮した有料マニュアルである。

このマニュアルには、AIと一緒に作業環境を構築するための考え方や手順、作業を進める際のルール、判断に迷ったときの考え方などをまとめている。

単に操作方法を並べた説明書ではない。AIとどのように協力し、何を確認し、どのように一つずつ形にしていくか。その進め方自体を、AIが参照できる形にしたものである。

### マニュアルを読み込むと、AIとの進め方が変わる

マニュアルを読み込んだAIは、そこに書かれたノウハウを参照しながら、読者の作業をサポートできるようになる。

例えば、こんな進め方ができる。

- **何から始めればいいか分からない。**  
  マニュアルの手順を踏まえて、最初に取り組むことを確認し、一つずつ進められる。

- **途中で分からないことが出てきた。**  
  AIに質問し、手順や考え方を確認しながら先へ進められる。

- **自分の環境では、説明どおりに進まない。**  
  状況をAIに伝え、マニュアルの方針を踏まえて、対応方法を一緒に考えられる。

- **次に何をすればいいか迷った。**  
  進捗や残っている課題を整理し、次の一歩を決める手助けをしてもらえる。

もちろん、AIがすべてを正しく理解し、自動で完成させてくれるわけではない。必要な確認や判断は人が行う。

それでも、何も知らない状態から一人で調べ続けるのと、実践のノウハウを共有したAIと相談しながら進めるのとでは、取り組みやすさが変わる。

**マニュアルは、知識を読むためだけのものではない。AIと一緒に実践するための道しるべなのである。**

### 一つできると、次にやりたいことが見えてくる

まずは、AIとのやりとりや作業内容を残し、次に活かす仕組みを作る。

それができたら、今度は別の作業にも応用してみる。自分に合うように手順を工夫する。さらに便利にできないか、AIと相談してみる。

最初は難しそうに見えたことが、一つずつ自分の手で形になっていく。

そして、できあがった仕組みは、そこで終わりではない。使いながら改善し、自分の仕事や活動に合わせて育てていける。

**「自分にもできた！」から、「次はこれをやってみたい！」へ。**

このマニュアルで目指しているのは、単に作業を終わらせることではない。AIと一緒に、自分でできることを増やしていく体験である。

最初から何でも知っている必要はない。分からないことがあっても、ノウハウを手がかりにAIと相談し、試して、修正しながら進めればいい。

一人では難しかったことにも、手が届くかもしれない。

その可能性を、実際の体験に変えていこう。

AIと一緒に、できることを増やしていこう。
