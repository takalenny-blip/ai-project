# ブログ画像の保存ルール

## 標準保存先

- 記事専用の画像は、記事IDに対応する既存フォルダー `docs/企画/BLOG-NNNN/images/` に保存する。
- ファイル名は記事IDを含め、例：`blog-0004-four-panel.png` のように用途が分かる名前にする。
- Blogger掲載用HTMLは、同じ記事フォルダーに保存した画像をGitHubのraw URLで参照する。
- 記事専用画像を `docs/site/images/` に追加しない。`docs/site/images/` はブログ全体で共用するサイト素材（例：サイトバナー）に限定する。
- 既存の画像フォルダーや保存ルールを確認してから作業し、記事ごとの新規フォルダーをむやみに増やさない。標準フォルダーが既にあれば再利用する。

## 変更時の確認

1. HTML内の画像URLが標準保存先を指していること。
2. 画像ファイルがGitHub上の指定パスに存在すること。
3. ビルド・回帰テストの画像URL期待値を更新すること。
4. 公開ページで画像表示を確認すること。確認できていない場合は「未確認」と記録する。
