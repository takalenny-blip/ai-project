# 002 再作業禁止ガード（たかの明示判断）

更新日：2026-10-16

## 強制ルール

- Dropbox作業管理統合ボードの項目002は、たか本人が状態を「完了」に変更した。これはGitHub側で日々の作業管理を続けないという判断に基づく。
- **002を再開・再検証・再実行しない。** 説明欄に旧文言「今回版は未作成・未検証」が残っていても、これを理由に状態を戻したり、002の作業を起票したりしない。
- 002の状態・説明欄・証拠欄を修正するためだけに、GitHubとDropboxの表示を同期させない。
- 既存のDropbox統合ボードは上書き・編集・削除しない。既存直チャット原本も変更しない。
- Dropboxへの日々の作業管理切替は、項目003以降の実作業として進める。002を再実行しなくても003の実装・検証を進めてよい。
- 002に触れる変更案が出た場合は停止し、変更せず、たかに確認する。既定動作は「002は完了・再作業禁止」。

このガードは項目002の状態を変更するものではなく、たかが設定した完了状態を誤って巻き戻さないための再発防止ルールである。
