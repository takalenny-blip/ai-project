GitHub 企画書および指示書などドキュメント保存および運用ルール（報告書編）
1. 目的
本報告書は、たかとJUNとバドの日常的な対話や作業の進捗、経験DBの蓄積状況を踏まえ、バド（全体設計・記事化担当）へ的確かつスムーズに情報を引き渡すための「報告書」の作成およびGitHubリポジトリへの保存運用に関する経緯と成果をまとめたものである。

2. 格納先フォルダ
GitHubリポジトリ内のパス: docs/

3. ファイル命名規則
形式: YYYY-MM-DD_HHMM_[ドキュメント種別]_[発信者]_[日本語のトピック名].md

例: 2026-09-05_1010_報告書_JUN_バドへの報告書運用ルール.md

4. 運用フロー
作業・対話の進行: 現場での作業（VAIO Pのセットアップ等）や検証を行う。

報告項目の整理: 一連の区切りや重要な進捗があった際、バドに共有すべき事項（事実、迷い、成果、経験DBのピース）をJUNが整理・ドラフト化する。

内容の確認: たかさんが内容を確認・承認する。

リポジトリへの格納: たかさんの手元で、指定された命名規則に沿って docs/ フォルダへファイルを追加・コミットし、リポジトリに蓄積・共有する。
