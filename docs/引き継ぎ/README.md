# 再開時の参照・環境固有の注意事項

> このREADMEは、フォルダー内に残す環境固有の履歴・注意事項を案内するもの。現在の作業状態、日常作業キュー、次の作業を記録する引き継ぎスナップショットではない。現行の共通運用ルールは `rules/運用ルール.md`、日常作業の状態・優先順位・次のアクションはDropbox固定ボードを参照する。

## 現行の参照先

1. `rules/運用ルール.md` と今回の作業に適用される個別ルールで、禁止事項・承認条件・停止条件を確認する。
2. 日常作業の状態・優先順位・次のアクションはDropbox固定ボード `/ChatGPT/Dropbox作業管理統合ボード.xlsx` から確認する。
3. 技術的な事実・仕様は対象のコード、設定、設計資料などの原本を確認する。
4. 変更履歴・検証証拠はPR、コミット、GitHub Actions、テスト結果を直接確認する。
5. このフォルダーの資料は、対象の環境・過去の作業経緯が今回の判断に関係する場合だけ参照する。

このフォルダーや過去ログから、現在の作業候補・優先順位・次の一手を復元しない。現在状態を説明するだけの別スナップショットを作成・維持しない。

## 環境固有の失敗・再試行条件

- 失敗や再試行注意を記録する場合は、可能な限り「対象環境」「失敗した操作」「再試行条件」をセットで残す。
- ある環境での失敗を、環境条件を確認せずに全環境共通の再試行禁止へ拡張しない。
- 同じ環境で既に失敗した手段は、環境条件が変わらない限り無条件に再試行しない。
- 環境が変わった場合は、同じ手段を改めて検証してよい。
- 現在の実行環境や利用可能な機能は、このREADMEや過去の記録から推測せず、必要になった時点で確認する。

## DIGA / DiMORAの履歴上の境界

- DIGA / DiMORA自動化の本線作業は、現行のバド単独運用では実機側の取得・操作まで完遂できないため、2026-09-21に断念した。既存成果・経験資産は破棄せず履歴として保持する。
- 明示的に再開する指示がない限り、過去の「次の一手」や実行手順を現在の作業として再開しない。
- 制限付きPCで使えなかったF12、DevTools、HTML確認、ネットワーク確認等は、そのPCでの失敗だけを理由に他環境でも不可と決めつけない。制限のない環境へ移った場合は、環境差を明示して改めて検証してよい。
- `GL_FAVPGM_DATA.record[]` の確認済み事実と、認証済みページをプログラムから取得する未解決課題を混同しない。
- 詳細な過去の調査対象・環境条件は `docs/引き継ぎ/DiMORA_work_pc_CDP取得.md` を参照する。ただし、その資料も現在の作業指示や環境状態の証拠として自動採用しない。

## 記録の扱い

- 直チャットは一次記録として原文を保持し、後から変更・削除・改名・上書き・置換しない。
- 環境固有の補足・訂正が必要な場合は、元の記録へ追記せず、適用ルールと承認条件に従って別資料へ記録する。
- このREADMEは現在状態の更新先ではない。作業状態や完了状態を追記して二重管理しない。
