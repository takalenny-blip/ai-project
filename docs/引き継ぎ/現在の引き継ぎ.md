**完了条件：** `chromium` の検索から、既知の一次記録 `048` と `~/.config/chromium-flags/launch-light.sh` まで到達できること。

関連EXP/REC：`経験ログ/EXP-0000000060.md`、`経験ログ/EXP-0000000060_REC-0000000010.md`
