# 現在の引き継ぎ

更新日：2026-09-08

## 対象

DIGA / DiMORA 自動化

## 現在の作業地点

Windows PCのChromeで、認証済みDiMORAのお気に入り番組一覧を表示できている。

今回の調査では、現在使っている制限のあるPCでブラウザ内部調査を続けるより、後日、制限のないPCで取得・解析を行う方針に切り替えた。

## 確定

- DiMORAのお気に入り番組一覧のHTML内に `GL_FAVPGM_DATA` が存在する。
- お気に入りデータは `GL_FAVPGM_DATA.record[]` に保持されている。
- 「もっと見る」は追加のサーバー通信ではなく、ページ内の `record[]` を10件ずつ表示するJavaScript処理である。
- 調査の主課題は「もっと見るの通信先を探す」ことではない。
- 次の本命は、認証済みDiMORAページを取得し、`GL_FAVPGM_DATA.record[]` を安全に読み出す方法の検証。
- 現在の制限付きPCでは、DevToolsやHTML確認のための操作に制約があり、これ以上無理に進めない。
- 認証済みページの取得・HTML解析は、後日、制限のないPCで実施する方針とした。
- VAIO Pには今回のWindows側調査で変更を加えていない。

## 未確定

- 認証済みDiMORAページをプログラムから取得する具体的方法。
- 認証状態を安全に扱う方法。
- 取得処理をVAIO Pへ移す具体的方法。
- 定期実行、変更検知、DIGA機種別制御、警告メールまで含めた現行仕様。

## 未着手

- 制限のないWindows PCでの認証済みページ取得の小規模実証。
- `GL_FAVPGM_DATA.record[]` のプログラムによる抽出実証。
- 抽出結果の保存・比較方法の検討。
- VAIO Pへの導入。

## 失敗・再試行注意

2026-09-08の再開時点で、**現在の制限付きChrome**では以下が効かなかった。

- F12
- Ctrl + Shift + I
- Ctrl + U

Chrome右上メニューからのデベロッパーツール操作も、クリックできない状態だった。

これは**その制限付きPC・その環境での失敗**であり、F12 / Ctrl + Shift + I / Ctrl + U / DevTools操作そのものを全面的に再試行禁止とする意味ではない。

したがって、**同じ制限付きPCでは同じ手順を最初から繰り返さない。一方、制限のないPCでは、これらを改めて試す価値がある。**

## 次に最初にやる操作

次に制限のないPCを使える時点で、以下の順で進める。

1. DiMORAへログインした状態を用意する。
2. F12 / Ctrl + Shift + I / Ctrl + U / DevTools等を、制限のない環境で必要に応じて試す。
3. HTML、ページ内部データ、必要ならネットワークやJavaScriptの動きを確認する。
4. 認証済みDiMORAページをプログラムから取得する経路を小さく検証する。
5. 取得したHTML等から `GL_FAVPGM_DATA.record[]` を抽出できることを実証する。

## やってはいけない手戻り

- **制限付きPCで**F12を再試行する。
- **制限付きPCで**Ctrl + Shift + Iを再試行する。
- **制限付きPCで**Ctrl + Uを再試行する。
- `GL_FAVPGM_DATA.record[]` が既に確認済みなのに、その存在確認へ戻る。
- 「もっと見る」の追加サーバー通信を前提に、そこから調査をやり直す。
  - ただし、制限のないPCでネットワークを確認すること自体は、ページ取得・認証方式を理解する目的なら実施してよい。
- VAIO Pへ先に変更を加え、Windows側の取得方式が未確定なまま実装を進める。
