# 現在の引き継ぎ

更新日：2026-09-08

## 対象

DIGA / DiMORA 自動化

## 現在の作業地点

制限のないWindows PCのChromeで、認証済みDiMORAのお気に入り番組一覧を表示し、ページ内の `GL_FAVPGM_DATA.record[]` をJavaScriptから取得できることを実証した。

## 確定

- DiMORAのお気に入り番組一覧のHTML内に `GL_FAVPGM_DATA` が存在する。
- お気に入りデータは `GL_FAVPGM_DATA.record[]` に保持されている。
- 「もっと見る」は追加のサーバー通信ではなく、ページ内の `record[]` を10件ずつ表示するJavaScript処理である。
- 制限のないWindows PCのChromeで、認証済みお気に入り一覧を表示できた。
- `GL_FAVPGM_DATA.record.length` を実行し、1件のデータが取得できることを確認した。
- `JSON.stringify(GL_FAVPGM_DATA.record[0], null, 2)` により1件の構造化データをJSONとして取得できた。
- `title`、`startDate`、`endDate`、`bcsNm`、`mode`、`requestId` など必要項目をJavaScriptで抽出できた。
- 抽出結果をJSON化し、`copy(...)` によりクリップボードへコピーできた。
- 今回の実証結果は `経験ログ/REC_EXP-0000000010_REC-0000000080.md` に記録した。
- ID管理台帳のEXP-0000000010の最終REC-IDをREC-0000000080へ更新した。
- VAIO Pには今回のWindows側調査で変更を加えていない。

## 失敗・再試行注意

2026-09-08の調査では、制限付きPCでは以下が利用できなかった。

- F12
- Ctrl + Shift + I
- Ctrl + U

Chrome右上メニューからのデベロッパーツール操作も、クリックできない状態だった。

これはその制限付きPC・その環境での失敗である。制限のないPCではDevToolsを利用して今回の抽出実証まで進められた。

PowerShell上でのPythonコマンド確認では、期待したPythonバージョン表示を得られておらず、Pythonによる自動取得は未確認のままとする。
