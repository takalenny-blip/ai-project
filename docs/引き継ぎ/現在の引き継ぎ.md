## 確定

- **「次回アクションとして明記する」だけでは、情報漏れ防止として不十分。**
- 次回操作以外にも、決定・変更・確定事実・失敗・未確定・次回判断・相談・依頼・関連資料・EXP/REC・禁止事項・未保存情報が発生する。
- セッション終了時は、これらを分類して棚卸しし、保存先と次回の取得場所を確認する必要がある。
- 「チャット→GitHub差分チェック」を行い、今回新たに発生した重要情報がGitHub上のどこかに対応していることを確認する。
- 相談・依頼は「次回アクションに書いた」だけで保存済みとは扱わない。
- JUNは固定工程ではなく、必要なときに助言・レビューを求める補助手段として利用できる。
- DiMORA取得方式についてJUNへ相談する場合も、JUNの意見だけで自動的に方針確定せず、たか＋バドで最終判断する。
- Windows + Chromeで認証済みDiMORAから `GL_FAVPGM_DATA.record[]` を取得できたことは既存の確認事実である。
- **最終運用環境の本命はVAIO P + Firefox ESR。** Chromeでの成功はFirefox ESRでの成功を意味しない。
- Chrome Remote Debuggingは現時点でWindows側の技術実証候補であり、本番方式として採用決定していない。
- Firefox ESRでの確認とVAIO P上での確認は別の状態として扱う。
