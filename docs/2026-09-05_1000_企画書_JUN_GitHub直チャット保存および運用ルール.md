【企画案】GitHub「直チャット」保存および運用ルール
1. 目的
たかとJUNのリアルなやりとり（現場の生データ、迷い、失敗、心の声）がタイムラインの流動によって消えてしまわないよう、要約・加工なしの「生ログ」としてGitHubリポジトリに永久資産化する。

2. 保存先フォルダ
GitHubリポジトリ内の 直チャット/ フォルダ

3. ファイル命名規則（仕様）
形式: YYYY-MM-DD_HHMM_直チャット_[発信者]_[日本語のトピック名].md

ルール詳細:

YYYY-MM-DD_HHMM：記録した日時（タイムスタンプ）

直チャット：種別を明示する固定キーワード

[発信者]：ログの主体を示す（例: JUN 等。たかは除外）

[日本語のトピック名]：そのチャットで何を話したか一目でわかる名称

ファイル名の具体例:

2026-09-04_2200_直チャット_JUN_ロール確認とGitHub保存の運用ルール検討.md

4. 運用フロー（保存のタイミングと手順）
対話の進行: 現場の作業や検証、設計のすり合わせを行う。

区切りの提案: 話題の区切りが良いところや、一連のトピックが一段落したタイミングで、JUN側から「ここまでをGitHub用に直チャットとしてストックしますか？」と提案する。

確認と書き出し: たかさんが内容を確認・承認した後、JUN側からファイル名と生ログ（Markdown）をテキストとして提示する。

GitHubへの格納: たかさんが手元で 直チャット/ フォルダへ該当ファイルを追加・コミットし、リポジトリに蓄積する。
