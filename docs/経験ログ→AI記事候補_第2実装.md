# 経験ログ → AI記事候補 第2実装

## 目的

第1実装で作った決定的な記事素材JSONを、AIが記事候補へ編集するための最小入力単位へ変換する。

## 今回の境界

- 入力：第1実装の schema_version: 1 JSON
- 出力：プロバイダ非依存のAI編集プロンプト
- 根拠：入力JSON内のEXP/RECのみ
- 許可：文章整理、順序変更、見出し化
- 禁止：本人発言・出来事・数値・因果関係などの補完、推測
- しないこと：Blogger投稿、公開、認証、外部通信

この実装ではAIサービスそのものを呼び出さない。まず何をAIへ渡し、何をAIに禁止するかを固定し、入力境界をテスト可能にする。

## 完了条件

1. 第1実装のJSONを受け取れる。
2. EXP/RECの内容がプロンプトへ保持される。
3. 推測・本人発言の捏造・外部通信を禁止する指示が含まれる。
4. 未確定事項を「記録上不明」として扱う指示が含まれる。
5. 不正なschema_versionを拒否する。
6. Blogger API・認証情報を導入しない。

## 次段

このプロンプトを実際のAI編集器へ渡し、生成された記事候補について「入力記録に根拠があるか」「未確定事項を勝手に埋めていないか」を検証する。Blogger投稿はその検証後に別工程として扱う。
