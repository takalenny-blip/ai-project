# 経験ログ → ブログ案 第5実装

## 目的
AI記事候補を、たかが内容を確認・採用判断できるブログ案として明示的に切り出す。

## 工程
経験ログ → 記事素材 → AI記事候補 → 根拠照合 → ブログ案（draft） → Blogger payload → Blogger下書き → 公開

## 契約
- title / intro / body / insights / uncertain_or_notes を保持する。
- groundingを保持し、一次記録へ追跡可能にする。
- status=draft、レビュー必須、採否pendingを明示する。
- Blogger投稿・公開・認証・外部通信は行わない。

## 完了条件
1. grounding検証済み記事候補からブログ案を決定的に生成できる。
2. ブログ案がdraftとして明示される。
3. レビュー必須・採否pendingが明示される。
4. 根拠が保持される。
5. Bloggerへの投稿状態が未実行であることを明示する。
6. テストがCIで成功する。
