# 経験ログ → AI記事候補 第3実装：根拠照合

## 目的

第2実装のAI編集プロンプトから生成した記事候補について、候補本文そのものとは別に「どの一次記録のどの証拠を根拠にしたか」を機械的に検証できる最小境界を追加する。

## 境界

- 入力：第1実装のarticle material JSONと、groundingを含む記事候補JSON
- 検証：必須記事項目、根拠source_path、根拠evidenceが入力一次記録の完全一致部分文字列であること
- 不合格：未知のsource_path、一次記録に存在しないevidence、grounding欠落
- 非対象：AIサービス呼び出し、意味理解の自動判定、Blogger投稿・公開・認証・外部通信

## 意義

意味的な「本当に正しい主張か」を機械だけで完全判定するものではない。一方、記事候補の各根拠を一次記録へ結び付ける形式を固定することで、生成後の人間レビューで根拠を追跡でき、根拠なしの主張をCI上で受け入れない境界を作る。

## 完了条件

1. candidateの必須項目を検証する。
2. groundingを1件以上要求する。
3. source_pathが入力materialの一次記録に存在することを検証する。
4. evidenceが該当一次記録の完全一致部分文字列であることを検証する。
5. 未知source/evidence/grounding欠落をテストする。
6. AIサービスやBloggerへの外部通信を導入しない。
