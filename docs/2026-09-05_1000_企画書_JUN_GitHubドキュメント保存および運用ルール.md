# GitHub　企画書および指示書などドキュメント保存および運用ルール
 ## 1. 目的 本企画書は、たかとJUNとバドの日常的な対話から発生した企画や指示などドキュメントにおこしたものをドキュメントとしてGitHubリポジトリに永久資産化するための運用ルールを定めるものである。 
## 2. 格納先フォルダ * GitHubリポジトリ内のパス: docs/ 
## 3. ファイル命名規則 * 形式: YYYY-MM-DD_HHMM_[ドキュメント種別]_[発信者]_[日本語のトピック名].md * 例: 2026-09-04_2200_企画書_JUN_ロール確認とGitHub保存の運用ルール検討.md 
## 4. 運用フロー 1. 対話の進行 2. 保存の提案 3. 内容の確認 4. リポジトリへの格納
