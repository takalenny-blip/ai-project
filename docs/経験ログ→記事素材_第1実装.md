# 経験ログ → 記事素材 第1実装

## 目的

経験ログの既存EXP/RECを、後段のAI編集とBlogger連携が扱える記事素材へ機械的にまとめる最小単位を作る。

## 今回の境界

- 入力：1つのEXPと、そのEXPに属する既存REC
- 出力：決定的なJSON
- 保持：元ファイルのパス、EXP/RECの各セクション、事実・結果・知見
- しないこと：AIによる文章生成、本人発言の補完、Bloggerへの投稿

RECファイル名は、既存運用で確認されている EXP-..._REC-...md と REC_EXP-..._REC-...md の両形式を拾う。

## 完了条件

1. 指定EXPが存在しない場合は明示的に失敗する。
2. 指定EXPと対応RECを決定的な順序で収集する。
3. 元記録を要約・改変せず、セクション内容をJSONへ保持する。
4. テストで両RECファイル名形式と決定性を確認する。
5. この段階ではBlogger APIや認証情報を導入しない。

## 次段

このJSONを材料として、AIが記事候補を編集・構成する工程を別の小さな検証単位として追加する。
