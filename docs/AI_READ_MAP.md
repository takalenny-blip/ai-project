# AI_READ_MAP — 最小読解案内

更新日：2026-09-14

現在の情報源を増やさないため、このファイルは**補助案内だけ**とする。現在状態や運用ルールをここへ重複記載しない。

## 基本

1. `BUD.md` — 現在の目的・現在状態・現在の次の一手
2. `rules/運用ルール.md` — 実際の作業手順・保存・横断ルール
3. 必要な場合だけ、関係する `docs/`、`projects/`、EXP/REC、`直チャット/` を読む

## 正本の優先順位

**BUD.md（現在状態） + rules/運用ルール.md（行動規則） > その他の資料**

`docs/全体進行設計図.md` はマクロな工程構造を確認したい場合だけ読む。`docs/引き継ぎ/現在の引き継ぎ.md` は直前セッションの再開情報であり、現在状態の正本ではない。

過去資料の「次にやること」を現在の命令として扱わない。
