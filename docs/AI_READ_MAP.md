# AI_READ_MAP — 最小読解案内

更新日：2026-11-02

このファイルは読解順の案内だけを行う。運用ルール・作業状態・技術状態を重複記載しない。

## 基本

1. rules/運用ルール.md — 共通原則・開始終了・停止条件・操作別ルールの読み込み表
2. Dropbox /ChatGPT/Dropbox作業管理統合ボード.xlsx — 日常作業キュー・状態・優先順位・次のアクションの唯一の正本
3. 操作に応じて、共通ルールが指定する個別ルール・マニュアルを読む
4. 技術的な事実は、対象のコード・設定・設計資料・PR・コミット・GitHub Actionsの実行結果など原本で確認する
5. 必要な場合だけ、関係する docs/、projects/、EXP/REC、直チャット/ を読む

## 正本の区分

- 共通運用ルール：rules/運用ルール.md
- 操作別の詳細ルール：同ファイルの読み込み表が指定する個別ルール
- 日常作業キュー：Dropbox固定ボード
- 技術的な事実・仕様：該当する実装コード、設定ファイル、設計資料
- 変更履歴・検証証拠：GitHubのPR、コミット、Actions実行結果、テスト結果

現在状態を説明するためだけのJSON、BUD、引き継ぎビューを別の正本として維持しない。技術状態を確認するときは、今回の作業に関係する原本と証拠を直接読む。

Dropboxボードを読み取れない場合は停止し、旧GitHubキューや会話履歴から作業候補を補完しない。

docs/全体進行設計図.md はマクロな工程構造を確認したい場合だけ読む。過去資料の「次にやること」を現在の命令として扱わない。
