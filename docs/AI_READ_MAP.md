# AI_READ_MAP — 最小読解案内

更新日：2026-10-30

現在の情報源を増やさないため、このファイルは補助案内だけとする。現在状態や運用ルールを重複記載しない。

## 基本

1. `docs/現在状態.json` — 技術状態・履歴・証拠の正本
2. Dropbox `/ChatGPT/Dropbox作業管理統合ボード.xlsx` — 日常作業キュー・優先度・状態・次のアクションの唯一の正本
3. `rules/運用ルール.md` — 共通原則・開始終了・停止条件・操作別ルールの読み込み表
4. 作業操作に応じて、同ファイルの操作別読み込み表が指定するルール本文を読む
5. `BUD.md` / `docs/引き継ぎ/現在の引き継ぎ.md` — 正本から生成された互換ビュー。正本との不一致時は使用せず、正本を優先する
6. 必要な場合だけ、関係する `docs/`、`projects/`、EXP/REC、`直チャット/` を読む

## 正本の優先順位

日常作業キューの唯一の正本はDropbox `/ChatGPT/Dropbox作業管理統合ボード.xlsx`。旧GitHub `work_items` / `next_step` は廃止済みで、参照・比較・作業選定・フォールバックに使用しない。技術状態・履歴・証拠は `docs/現在状態.json` を参照する。運用ルールは共通ルールと操作別ルールを分け、読み込み先の振り分けは `rules/運用ルール.md` の表だけを正とする。

Dropboxボードを読み取れない場合は停止し、旧GitHubキューや古い生成ビューへフォールバックしない。

`docs/全体進行設計図.md` はマクロな工程構造を確認したい場合だけ読む。過去資料の「次にやること」を現在の命令として扱わない。
