# AI_READ_MAP — 最小読解案内

更新日：2026-11-02

現在の情報源を増やさないため、このファイルは読解順の補助案内だけとし、現在状態や運用ルールを重複記載しない。

## 基本

1. `rules/運用ルール.md` — 現在状態・共通運用ルールの唯一の正本
2. Dropbox `/ChatGPT/Dropbox作業管理統合ボード.xlsx` — 日常作業キュー・優先度・状態・次のアクションの唯一の正本
3. 操作に応じて、`rules/運用ルール.md` の読み込み表が指定する操作別ルールを読む
4. 必要な場合だけ、関係する `docs/`、`projects/`、EXP/REC、`直チャット/` を読む

## 正本の役割

現在状態・共通運用ルールは `rules/運用ルール.md`、日常作業キューはDropbox固定ボードを参照する。過去の状態資料・会話履歴・成果物内の「次にやること」を現在の命令として扱わない。

Dropboxボードを読み取れない場合は停止し、過去ログや旧資料から作業候補を復元しない。

`docs/全体進行設計図.md` はマクロな工程構造を確認したい場合だけ読む。
