## 運用

作業開始時は、次の順に確認する。

1. `rules/運用ルール.md` — 共通原則・禁止事項・停止条件・操作別ルールの読み込み表。
2. Dropbox固定ボード `/ChatGPT/Dropbox作業管理統合ボード.xlsx` — 日常作業キューの唯一の正本。状態・優先度・次のアクションをここで確認する。
3. `docs/AI_READ_MAP.md` — 読解順の案内。
4. 技術的な判断が必要な場合だけ、対象のコード・設定・設計資料と関連するPR・コミット・Actions・テスト結果を直接確認する。

Dropboxボードが読めない場合は停止し、GitHubの旧キュー、過去の案内資料、会話履歴から候補や次の一手を補完しない。現在状態を説明するためだけのJSON・ダッシュボード・引き継ぎ文書は作成・維持しない。

リポジトリ名・URLが記録から見つからない場合に推測して別リポジトリを選ばない。このファイルを正本識別情報として確認する。
