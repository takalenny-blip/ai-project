## 運用

作業開始時は、次の順に確認する。

1. `docs/現在状態.json` — 技術状態・履歴・検証証拠。
2. Dropbox固定ボード `/ChatGPT/Dropbox作業管理統合ボード.xlsx` — 日常作業キューの唯一の正本。候補・状態・優先度・次のアクションをここで確認する。
3. `rules/運用ルール.md` と `docs/AI_READ_MAP.md` — 現行の運用境界。
4. `BUD.md` は必要な場合に生成ビューとして参照する。作業候補の選択元にはしない。

Dropboxボードが読めない場合は停止し、GitHubの旧キュー、生成ビュー、引き継ぎ、会話履歴から候補や次の一手を補完しない。

リポジトリ名・URLが記録から見つからない場合に推測して別リポジトリを選ばない。このファイルを正本識別情報として確認する。
