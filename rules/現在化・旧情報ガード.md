# 現在化・旧情報ガード

このファイルは rules/運用ルール.md を補助し、過去の「次の一手」や古い説明を現在の命令として再実行する事故を防ぐ。

## 正本の区分

- 日常作業キュー・候補・優先度・次のアクション：Dropbox固定ボード /ChatGPT/Dropbox作業管理統合ボード.xlsx
- 共通運用ルール：rules/運用ルール.md
- 操作別の詳細ルール：共通ルールの読み込み表で指定された個別ルール
- 技術的な事実・仕様：対象のコード、設定、設計資料
- 変更履歴・検証証拠：PR、コミット、Actions実行結果、テスト結果などの原本

## 必須確認

1. 作業候補はDropbox固定ボードから取得する。
2. 技術的な状態を判断するときは、対象に関係する実装・設定・PR・コミット・Actionsの原本を直接確認する。
3. 過去のチャットや古い作業説明にある「次の一手」を、現在の指示として採用しない。
4. 実行したことと検証できたことを区別し、確認できない事項は「未確認」とする。
5. 同じ確認を理由なく繰り返さず、新しい証拠や状態変化がある場合だけ再確認する。

現在状態を説明するためだけのJSON・BUD・引き継ぎビューを、独立した正本や作業再開の入口として維持しない。
