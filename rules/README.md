# rules — 運用ルール入口

共通原則・開始終了・停止条件・操作別ルールの読み込み表は、**`rules/運用ルール.md`** を参照する。

操作別の詳細ルール正本：

- `rules/直チャット保存.md`：直チャット保存・保存要求・保存結果確認
- `rules/ブログ制作.md`：ブログ企画・調査・構成・執筆・HTML整形・公開先運用
- `rules/ブログ画像素材管理.md`：ブログ画像素材の管理。ブログ画像操作時はブログ制作ルールと併読
- `rules/構造変更時・独立監査ガード.md`：構造変更時だけ適用する独立監査
- `rules/再開・検索ガード.md`：再開・検索時に該当条件が成立した場合に適用

情報源を重複させない。操作別の読み込み先は `rules/運用ルール.md` の表を唯一の振り分け表とし、このREADMEに詳細ルール本文や振り分け条件を複製しない。

- `docs/現在状態.json`：技術状態・履歴・検証証拠の正本
- Dropbox `/ChatGPT/Dropbox作業管理統合ボード.xlsx`：日常作業キュー・優先度・状態・次のアクションの唯一の正本
- `BUD.md`：`docs/現在状態.json` から生成される互換ビュー。日常作業キューの正本ではない
