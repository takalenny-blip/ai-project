# 現在有効な運用ルール

このディレクトリは、過去の作業記録ではなく、現在有効な運用ルールの入口です。

## 正本

**作業手順・運用フロー・横断的なルールは `rules/運用ルール.md` に一本化する。**

このファイルで個別ルールを増やさず、詳細は正本へ集約する。

## 重要な考え方

1. たかを中心に、たか＋バドで進める。JUN・Claudeその他は必要な場合だけ使う。
2. 過去に誰が何を担当したかは、現在の固定役割を意味しない。
3. 過去ログの「次にやること」は歴史上の計画であり、現在の命令ではない。
4. 現在の目的・状態・次の一手は `BUD.md` を基準とする。
5. 直チャットは原文を一次記録とし、1ターン1ファイルで即時保存する。
6. ユーザーが貼ったJUN・Claude等の他AI回答も、提示された原文を省略・要約・再構成せず保存する。
7. 網羅性が目的の過去記録調査では、REC全件列挙・出所追跡・Coverage確認を行う。
8. 同じ環境・条件・方法で既知の失敗を無条件に繰り返さない。
9. 認証情報等の秘密情報をチャットやGitHubへ記録しない。

## 読み方

1. `BUD.md` — 現在の目的・現在状態・現在の次の一手
2. `rules/運用ルール.md` — どう動くか、どう記録するか
3. 必要な個別資料

`docs/AI_READ_MAP.md` は読解順の補助マップです。
